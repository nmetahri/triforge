# i3-gnome session files

Vendored from [i3-gnome/i3-gnome](https://github.com/i3-gnome/i3-gnome) at commit
[`5b7d84e`](https://github.com/i3-gnome/i3-gnome/tree/5b7d84e054f81154f43a4699ad08bffdd71683d9)
(the repository is archived since November 2023). Only the session files and the `Makefile` are kept;
they are distributed under the MIT license in [`LICENSE`](LICENSE).

`sudo make install` registers the "I3 + GNOME" session, selectable from the login screen.
The triforge i3 installer runs it for you.
